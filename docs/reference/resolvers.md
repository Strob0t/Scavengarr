# Hoster resolvers

> **Purpose:** The resolver list with every resolver's domains, generated by `scripts/generate_resolver_list.py` from the resolver registrations; do not edit by hand.

Every resolver below is registered by `build_hoster_resolvers()` in `src/scavengarr/interfaces/composition.py`.
How the registry dispatches a link to a resolver and judges its answer: [Hoster resolvers](../current/hoster-resolvers.md).
*What it does* is the first sentence of the resolver module's docstring, which describes the technique in full.
*Capture* marks a resolver that can take the stream from the stealth browser.
*Bound* names what the CDN binds a video URL to: `address` sends the file through the file proxy, header names make `/play` resolve the link per player.
*Check* marks a resolver whose streams the playback check reads with `stremio.verify_streams` off too.

63 resolvers: 28 individual ones, 10 generic DDL hosters and 25 XFS hosters.
