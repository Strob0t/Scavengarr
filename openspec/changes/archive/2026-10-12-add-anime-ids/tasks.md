## 2. Port and adapters

- [x] 2.1 `domain/ports/anime_ids.py`: `AnimeIdResolverPort.translate(request) -> StremioStreamRequest | None` (the translated `tt` request: IMDb id, content type, season, episode) and the null object `NO_ANIME_IDS` (translates nothing); tests first.
- [x] 2.2 `infrastructure/anime/kitsu_addon.py`: (done as `cached()` and `fetch()` instead of `record(fresh=)`: the resolver decides when to ask the addon) `KitsuAddonClient.record(content_type, kitsu_id, *, fresh=False)` fetches `/meta/<type>/kitsu:<id>.json` from the Anime Kitsu addon with the shared httpx client (5 s timeout, one attempt), reduces it to `{imdb_id, type, episodes: {number: [season, episode, mapped]}}` and caches it 30 days under `anime_ids:addon:v1:<type>:<id>`; `fresh=True` bypasses the cache. respx tests with recorded JSON fixtures (`tests/fixtures/json/kitsu/`, trimmed to a few videos): a series, a movie, a video without `imdbSeason`, a 403, a timeout, a cache hit.
- [x] 2.3 `infrastructure/anime/id_lists.py`: `AnimeIdLists.entry(kitsu_id)` downloads Fribb's `anime-list-full.json` on first use (60 s timeout, one attempt; parsed in a worker thread), reduces it to the records with a Kitsu id (`imdb_id[0]`, `type`, `season.tvdb`, `episode_offset.tvdb`), keeps the map in memory and caches it 7 days under `anime_ids:lists:v1`; a failed download logs `anime_id_lists_failed` and is retried after an hour; one load in flight at a time. respx tests with an excerpt fixture: a placed series, a movie, a record without a season, an unlisted id, a download failure with the hour's hold-off, a cache hit without a download.
- [x] 2.4 `infrastructure/anime/resolver.py`: `KitsuAnimeIdResolver(addon, lists)` implementing the order of `design.md` (addon record → video's IMDb numbering, else its own numbering → one refetch for an unknown episode → the list → `None`), the content type from the source, `anime_id_translated` (kitsu id, episode, IMDb id, season, episode, `source` `addon` | `kitsu` | `lists`) and `anime_id_lookup_failed` (kitsu id, episode, `reason`); unit tests per path with fake clients.
